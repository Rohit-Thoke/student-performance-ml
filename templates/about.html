College Machine Learning Mini Project

Student Performance Prediction System

Complete Technical Documentation, ML Mechanics & Academic Viva Preparation Guide

Problem Statement

Educational institutions face challenges in identifying at-risk students before final examinations occur. Traditional evaluation models fail to capture multi-dimensional factors such as attendance trends, continuous assignment scores, internal assessment performance, and sleep/study habits. Early identification through predictive machine learning empowers educators to provide timely remedial guidance.

Project Objectives

  • Demonstrate complete end-to-end Machine Learning pipeline from raw CSV to deployed web system.
  • Clean, preprocess, and standardize academic and lifestyle student feature vectors.
  • Train and compare 4 supervised classification algorithms (Logistic Regression, Decision Tree, Random Forest, KNN).
  • Provide explainable, data-driven academic insights alongside prediction confidence probabilities.

Supervised Machine Learning Algorithms Breakdown

1. Logistic Regression

A baseline linear model that applies the Softmax function to linear feature combinations to estimate multi-class probability distributions for Poor, Average, and Good classes.

Formula: $P(Y=k|X) = \frac{e^{w_k^T X + b_k}}{\sum_j e^{w_j^T X + b_j}}$

2. Decision Tree Classifier

Splits features recursively by selecting threshold values that minimize node Gini Impurity or Information Entropy, producing interpretable decision rules.

Formula: $Gini = 1 - \sum_{i=1}^C p_i^2$

3. Random Forest Classifier

An ensemble bagging method constructing 100 decorrelated decision trees on bootstrap dataset samples. Final prediction is aggregated via majority voting.

Aggregated Prediction: $\hat{Y} = \text{mode}(T_1(X), T_2(X), ..., T_B(X))$

4. K-Nearest Neighbors (KNN)

Non-parametric instance-based classifier calculating Euclidean distance $d(x, y) = \sqrt{\sum (x_i - y_i)^2}$ to find $k=5$ closest training instances in feature space.

Distance: $d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{i=1}^n (a_i - b_i)^2}$

College Project Viva Evaluation Questions & Answers

Exam Preparation

Q1: Why is Data Preprocessing crucial before feeding data into ML models?

Answer: Raw datasets contain missing values, outliers, and differing feature scales (e.g., Attendance is 0-100%, Backlogs are 0-5). Without preprocessing: (1) missing values cause runtime errors, (2) unscaled features cause distance-based algorithms like KNN to be dominated by larger range features, and (3) categorical variables ('Yes'/'No') cannot be mathematically computed.

Q2: What is Data Leakage and how did you prevent it in your project?

Answer: Data leakage occurs when information from the test dataset leaks into the training pipeline (e.g., fitting StandardScaler on the entire dataset before splitting). We prevented leakage by performing `train_test_split` first, fitting the `StandardScaler` strictly on `X_train`, and using that fitted object to transform `X_test` and single prediction inputs.

Q3: Why did Random Forest outperform single Decision Trees in your evaluation?

Answer: Single Decision Trees are prone to overfitting high-variance training data. Random Forest builds 100 decorrelated decision trees using bootstrap sampling (bagging) and random feature subsetting. Averaging predictions across multiple trees reduces overall variance while keeping bias low, leading to higher test set accuracy.

Q4: What evaluation metric is most important for identifying 'Poor' at-risk students?

Answer: Recall for the 'Poor' class is most critical. High recall minimizes False Negatives—meaning we avoid failing to detect an at-risk student who truly needs academic intervention.

Q5: How does your web app load saved trained models without retraining every request?

Answer: During training, fitted model objects and scaler pipelines are serialized to disk as binary `.joblib` files in `models/trained_models/`. When a user submits a prediction request, Flask deserializes the saved `.joblib` binary using `joblib.load()`, executing instant inference in milliseconds.
