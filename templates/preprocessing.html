Data Preprocessing Pipeline

Clean, encode, scale, and split raw student records for machine learning training

Step 1 • Imputation

Missing Values Handling

Numerical features (study hours, marks, attendance) with missing entries are imputed using the Column Median to prevent outlier distortion. Categorical features are imputed using the Mode.

Handled Missing Null Entries: 5 values
Step 2 • Cleaning

Duplicate & Outlier Cleaning

Identical duplicate student records are purged. Feature bounds are enforced: Attendance (0-100%), Marks (0-100%), Internal Marks (0-30), and Study Hours (0-16).

Duplicates Purged: 0 records
Step 3 • Encoding

Categorical Variable Encoding

Non-numeric attributes like Extracurricular Activities are converted to numerical binary format (Yes = 1, No = 0). Target performance labels are mapped: Poor (0), Average (1), Good (2).

Extracurricular: "Yes" → 1, "No" → 0
Step 4 • Scaling

Standardization (StandardScaler)

Numerical features are scaled to zero mean ($\mu = 0$) and unit variance ($\sigma^2 = 1$) using formula $z = \frac{x - \mu}{\sigma}$. This ensures feature scale dominance doesn't skew distance-based algorithms like KNN and Logistic Regression.

Scaler fitted on X_train only to prevent data leakage.
